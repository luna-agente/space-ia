# Space-IA

A 3D space construction sandbox built with Godot 4.7.2.

We are starting with a minimal technical foundation and growing the game through small, playable increments.

## First milestone

- 3D space scene
- Player ship
- 6DOF movement
- Asteroids
- Grid-based construction
- Add/remove blocks

## Project layout

```text
scenes/       Godot scenes
scripts/      Game logic
assets/       Models, textures, materials and audio
tests/        Automated and experimental tests
docs/         Design and technical notes
```
